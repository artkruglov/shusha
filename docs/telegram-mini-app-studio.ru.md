## Зачем
Картинки и видео — вторая по частоте просьба семьи после дел: открытки к поводу, «поставь диван на фото комнаты»,
эскиз стола по размерам, улучшить фото для сторис, оживить фото «пролётом дрона», инфографика. Всё это бот уже умеет
(`generate_image` с правкой по исходнику, видео Seedance из первого кадра, галерея), но только в переписке: надо знать,
что попросить, и как. Meta сделала то же отдельным продуктом (Muse Image: чистка, раскраска старых фото, «золотой час»,
смена фона, сборка из нескольких снимков; Muse Video — с озвучкой, пока анонс).

## Что делает Студия
Один экран «Создать» в Mini App и тот же путь в чате.
1. **Исходник:** фото с телефона, из галереи «Мои картинки» или последнее фото из чата; можно без исходника.
2. **Что сделать** — крупные карточки-рецепты с примером «до/после»:
   - Улучшить фото (свет, цвет, чёткость), Для сторис 9:16, Золотой час, Убрать лишнее, Сменить фон, Раскрасить старое;
   - Примерить в интерьере («диван у стены», «шторы»), Эскиз по размерам;
   - Открытка к поводу (день рождения из памяти семьи: «бабушке Ирине, в субботу»), Картинка по описанию;
   - Оживить фото (4–8 с), Видео по описанию.
3. **Уточнение одной строкой** (необязательно): «серый диван, мягкий свет».
4. **Сделать:** карточка прогресса «Шуша рисует… обычно до минуты», можно закрыть приложение — результат придёт в чат.
5. **Результат:** до/после ползунком, «Ещё вариант», «Поправить» (строкой), «Оживить», «Отправить Юле», «В семейный чат»,
   «Сохранить в Фото». Все версии лежат стопкой у исходника.

## Как устроено
- **Без модели-разговора.** Рецепт — это готовый шаблон запроса, собранный кодом из выбранного рецепта и строки уточнения;
  страница присылает id рецепта, файл и строку, текст запроса модели картинок собирает сервер (как подсказки «Умеет»).
  Вызов идёт в тот же сервис генерации, что и инструмент чата (`image-generation`, `video-generation`), с тем же журналом
  операций (повтор не платит дважды), той же папкой и лимитом семьи (`budgetGate`).
- **Загрузка фото** из приложения: отдельный маршрут с большим телом (до 10 МБ, тип по сигнатуре), файл кладётся в
  личную папку; nginx — свой `location` с `client_max_body_size 10m` и пределом частоты.
- **Доставка:** результат в галерее и в личке (через `sendAuthorizedWorkspaceFile`), «В семейный чат» — только по нажатию.
- **Деньги и пределы:** картинка — копейки, видео — дорого: видео только с явным «Сделать видео» и показом цены «≈ $0,3»,
  дневной предел на человека, бюджет семьи.
- **Приватность:** фото детей и лиц остаются в папке семьи; ничего не публикуется без нажатия; рецепты «заменить лицо»,
  «сделать похожим на знаменитость» не делаем.

## Порядок
1. Макеты Студии (Codex, `gpt-6-astra`, в стиле v9).
2. Бэкенд: рецепты, загрузка фото, запуск генерации без разговора, прогресс, доставка (3–4 дня).
3. Экран Студии и «до/после» (2 дня).
4. Видео и «Оживить» с ценой и подтверждением (1–2 дня).
