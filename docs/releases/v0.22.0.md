# v0.22.0

Обновление за 1–23 октября 2026. Главное: приложение внутри Telegram (Mini App), группы, гостевой режим,
несколько семей на одной установке и знакомство для новых людей. Ещё надёжность очереди и вызовов модели.

## Приложение внутри Telegram

- Mini App по кнопке «Дела»: экран «Сегодня», который учится порядку блоков, доска, карточка дела с «Беру»,
  «Перенести», «Передать…», закрытое за неделю, «Давно без движения» с разбором по одному.
- Вкладка «Семья»: традиции и идеи, области заботы, решения, личное время, кто в семье и её чаты.
- Студия: картинки по рецептам («Улучшить фото», «Открытка к поводу» и другие), фото с телефона, версии;
  «Мои картинки и файлы» с поиском по описанию.
- «Надиктовать»: запись проходит то же распознавание речи, что и голосовое в чате.
- Страницы проектов, напоминания, память, настройки сводки.

## Дела, проекты и коуч

- Проекты ведёт навык project-coach: уточняет дела как GTD-коуч и делает проект только после «да» человека.
- Доска дел приходит отдельным сообщением после ответа; кнопки «Беру», «Сделано», «Помоги начать» без модели.
- Утренняя сводка семьи и группы, «фишки» по тому, что человек ещё не пробовал, вечерний итог.
- Подтверждение записи говорит, куда записано и кто видит; видимость спрашивается один раз.

## Группы и гостевой режим

- Обычные группы семьи с заявками на вход, приветствием и «Позвать людей»; группа без семьи со своей областью
  RLS и своим бюджетом.
- Гостевой режим (Bot API 10.0): упоминание бота в любой переписке получает один ответ с поиском, без памяти.
- Посты каналов (rich-сообщения) читаются как обычные сообщения; медиа во внешней группе только по гранту
  (по PR #17 @ilkruglov).

## Несколько семей и вход

- На одной установке может жить несколько семей; вход по ссылке со словом (`/signup`), лист ожидания,
  закрытый вход без кода ошибки и с уведомлением оператору.
- Знакомство для новых людей: карточки при старте, кнопки первых шагов и восемь шагов квеста с прогрессом в
  Mini App (миграция 197).
- Месячный бюджет модели на семью, `/feedback`, `/export`, `/delete_me`, `/delete_family`.
- Имя бота и все его @username настраиваются окружением (`TELEGRAM_AGENT_NAME`, `TELEGRAM_BOT_USERNAME_ALIASES`).

## Надёжность

- После `HookNotFoundError` сообщение больше не передаётся повторно: в Eve 0.40.0 ран к этому моменту уже
  запущен, повтор мог ответить дважды. Тексты сбоев для людей без внутренних кодов.
- Дедлайн ответа модели: 8 минут до первого события, 4 минуты простоя; keep-alive провайдера таймер не сбрасывает.
- Отправка в Telegram выдерживает лимиты и 429 по каждому чату отдельно.
- Блокировки умерших воркеров graphile-worker снимаются при старте, зависшие запуски подхватываются.
- Голос распознаётся локально (GigaAM) или через Groq — по конфигурации.
